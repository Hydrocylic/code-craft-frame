# 框架笔记

> 框架版本: v2.0

---

## 目录说明

本目录记录框架自身的思考——不是给框架使用者看的，而是给框架维护者和迭代者看的。

### spec/ — 规范区

框架设计的**规范化文档**。记录"应该怎么做"：

- 设计意图（为什么某个规则是这样定的）
- 命名约定（模板、目录、字段的命名规范）
- 模板规范（模板文件的结构要求）
- 字段定义（meta.yaml 等配置文件的字段语义）

**规范区的变更是严肃的**，需要同步更新 FRAMEWORK.md 和 CHANGELOG。

### explore/ — 探讨区

框架的**局限性和可调整内容**。记录"为什么这样设计""有哪些已知局限""什么场景下可能需要调整"：

- 设计决策记录（为什么选 A 不选 B）
- 已知局限性（当前版本的边界在哪里）
- 可调整内容（哪些规则是柔性的，可以在特定场景下偏离）
- 未来改进方向（已识别但尚未实现的想法）
- 历史演进（从旧版本中学到了什么）

**探讨区的内容是开放和反思性的**，不强制同步到其他文档。当某个探讨结果足够成熟时，提升到规范区。

---

## 与外部 notes/ 的关系

仓库根目录的 `notes/` 是**框架使用者的笔记**（学习记录、跨项目概念等）。

`_framework/notes/` 是**框架自身的笔记**（设计反思、局限性、改进方向）。

当仓库作为框架的"母库"时，`_framework/notes/` 直接服务于框架迭代；当仓库作为框架的"消费者"时，使用者可以不关注此目录。
