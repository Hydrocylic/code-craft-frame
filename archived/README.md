# archived

本目录保存从当前框架正文退役的材料，供追溯与以后细分整理；**不是当前规则，不参与默认阅读，也不要求维护内部链接**。

- 退役内容按原路径镜像在 `archived/_framework/` 下，便于与 `_framework/` 对照。
- 当前规则以 `_framework/` 与根 `AGENTS.md` 为准；`archived/` 中的做法不自动恢复为授权或默认流程。
- 删除由仓库所有者人工决定；本目录不设自动清理。
